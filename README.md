# Serra

A React Native health and wellness tracking app.

## Setup

1. Install dependencies: `npm install`
2. Create `.env` file with your Supabase credentials
3. Run the app: `npm start`

## Features

- Dashboard with health metrics
- Sleep tracking
- Exercise logging
- Nutrition tracking
- Cycle tracking
- Wearable device integration

## Tech Stack

- React Native
- Expo
- Supabase
- TypeScript
- Tailwind CSS
